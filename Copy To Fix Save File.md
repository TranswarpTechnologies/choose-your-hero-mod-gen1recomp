Copy and paste the following text to fix your save file, as instructed in the tutorial:
```
 meta = {
    engine = "0.1.75",
    format = 4,
    mods = {
      [1] = {
        api = 2,
        id = "choose_your_hero",
        version = "1.1",
      },
  modData = {
    choose_your_hero = {
      player = "green",
      rival = "yellow",
    },
  },
```
If you have other mods in your save file, make sure to copy-paste this around them.
<br> Adjust the number in the box so that you don't overwrite or cause a conflict with another mod.
<br>
<br> If your player character is Red (male), then change player = "green" to player = "red".
<br>
<br> If your Rival character is Blue (male), then change rival = "yellow", to rival = "blue".
